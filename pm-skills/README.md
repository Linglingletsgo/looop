# PM methods for looop

Personal noncommercial skill pack. Adapted 2026-10-17; changes remove fixed counts, human-only menus, default calendars, automatic audit chains and unbounded report creation. Methods return caller-owned state and never extend project authority.

Project-owned skills take precedence. The loader includes relevant default methods only for a stated project-method gap; `investigation` is included with default methods. Exact runtime bytes and pinned upstream versions are in manifest.json. Original reviewed sources and original LICENSE files are retained in upstream/ for audit, not injected wholesale into each run. Consult original sources for background; do not inherit their additional workflow or authority.

## Standalone use

From a project conversation, first read the project's rules and current state. If project methods do not cover the question, explicitly read the relevant pm-skills/<method>/SKILL.md and investigation/SKILL.md from your looop checkout. Apply the method to the project's existing state mechanism. Paperclip is not required; do not copy this pack into business projects or replace their roles.
