# competitive-research

Research alternatives only to answer the named product decision. Select competitors or existing workarounds relevant to this project's users; justify inclusion without fixed counts.
Inspect current official product/pricing/release documentation and independent user evidence where available. Record source dates and separate observed capabilities, vendor claims, inference and gaps. Do not invent market share, customers, pricing or roadmap plans.
Compare the dimensions that matter to the user's job. Explain which findings change the proposed outcome, which contradict it and where the existing product already solves it. A competitor having a feature does not establish demand for copying it.
Return a concise recommendation, alternatives rejected and unresolved evidence. Use the caller's schema, not a separate report series or four-option menu. If public evidence cannot support the decision, report insufficient_evidence.
